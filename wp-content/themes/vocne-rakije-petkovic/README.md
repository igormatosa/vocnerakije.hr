# Voćne rakije Petković WordPress theme

## Installation

1. Compress the `vocne-rakije-petkovic` directory as a ZIP file.
2. In WordPress, open **Appearance → Themes → Add New → Upload Theme**.
3. Activate the theme.
4. Open **Appearance → Theme Setup** and optionally import the included starter content.
5. Save **Settings → Permalinks** once after import.

## Editing content

- **Appearance → Customize**: homepage text, hero and slider images, story image, contact data, final call to action.
- **Products**: product descriptions, featured image, category, packaging, two price columns and product gallery.
- **Pages**: About, Contact and other editable pages.
- **Posts**: blog/news content.
- **Appearance → Menus**: navigation and link labels.
- **Settings → General**: site title and tagline.

## WooCommerce later

The theme uses WordPress product posts and stores packaging in `_vrp_packaging`. Add WooCommerce later by mapping these products to WooCommerce products or migrating the data. The visual theme does not depend on WooCommerce.

No paid plugin is required. The theme uses no ACF dependency.
